Azure storage accounts are an Azure resource type that contain various storage services. 

These services include:

| Storage Service | Description |
| ---- | ---- |
| Blob Storage | Designed for general use, flat, unstructured data. |
| Data Lake Storage | A highly scalable, hierarchical unstructured data, with extra features suitable for Big Data workloads.  |
| Azure Files | A mountable file system. |
| Table Storage | For non-relational structured data. |
| Premium Block Blobs | A service that supports higher transaction workloads and provides lower latency. |
| Premium File Shares | A more performant file share that will now support NFS in addition to SMB. |
| Premium Page Blobs | A more performant page page service following the managed disk pricing model. |
